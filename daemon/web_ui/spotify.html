Подключите аккаунт Spotify

Вход открывает поиск, плейлисты и избранное. Для воспроизведения на станции нужен Spotify Premium.

Откройте «Музыка → Spotify» в веб-пульте на телефоне.

Настройка Client ID
  1. Создайте приложение в Spotify for Developers и выберите Web API.
  2. Добавьте Redirect URI и разрешите в настройках приложения вход вашему аккаунту.
  3. Скопируйте Client ID из приложения.
Открыть вход Spotify ↗

После входа скопируйте весь адрес из строки браузера, даже если страница 127.0.0.1 не открылась.
