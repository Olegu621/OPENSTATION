# Установка OpenStation Max

> Пользователи сообщили об успешной работе установщика. Перед прошивкой подготовьте способ восстановления: установка перезаписывает системные разделы.

Программа для Windows содержит необходимые инструменты и Python; отдельно устанавливать их не нужно. При первом запуске она скачивает архив разделов OpenStation Max v1.5.1 с GitHub (около 726 МиБ), проверяет размер и SHA-256 архива и каждого из трёх образов. Нужны интернет и несколько гигабайт свободного места. Это архив разделов, а не полный образ USB Burning Tool; он не содержит проверенного комплекта всех разделов для восстановления любой станции.

1. Подключите только Яндекс Станцию Макс к сервисному USB, подайте штатное питание и откройте установщик. USB-идентификатор общий для устройств Amlogic, поэтому программа не может сама подтвердить модель или ревизию.
2. Нажмите «Проверить подключение и установить» и прочитайте предупреждение. Для установки драйвера может потребоваться запуск с правами администратора.
3. Программа проверит образы и ответ устройства через `update.exe`. Если устройство не принимает команды, она остановится до записи. Автоматический переход в другой режим не выполняется.
4. Последовательно записываются `vbmeta`, `vendor`, `system`. Затем обязательно запускается `service_flash/after_ubt.bat`: `store init`, `amlmmc enc`, `setenv silent 0`, `setenv lock 10000000`, `setenv avb2 0`, `saveenv`. При ошибке команды сценарий продолжает выполнять оставшиеся команды и в конце сообщает об ошибке. Если процесс зависнет, общий тайм-аут прекратит его.
5. Программа не очищает `data`, `cache` и `misc` и не перезагружает станцию автоматически. Сообщение о завершении означает только завершение записи и команд, а не успешную загрузку. После завершения снимите сервисную перемычку и перезапустите питание. При ошибке сохраните журнал и не считайте установку завершённой.

Сборка из исходников на Windows: установите Python с PyInstaller и .NET Framework 4.x; запустите `powershell -ExecutionPolicy Bypass -File scripts/build_installer.ps1`. Файл появится в `dist/OpenStationFlasher.exe`. Локальные тесты: `python -m unittest discover -s installer -v`. Они имитируют инструмент и не проверяют запись на устройство.
